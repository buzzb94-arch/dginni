# Карточки ДЖИНН

33 отдельных PNG из исходной папки images. Ориентация сохранена по фотографиям, сопоставленным с сайтом: 25 ландшафтных, 2 портретных, 6 квадратных. Почти квадратное фото ph-metr-3 оформлено квадратным.

Тексты сверены с https://buzzb94-arch.github.io/dginni/. Дата проверки: 14 октября 2026 года.

Четыре исходных файла повторяются: gallery-4 = app-aqua, gallery-6 = app-greenhouse, ph-controller-4 = gallery-3, ph-metr-4 = hero. Для них сохранены отдельные файлы с исходными именами.

Оригиналы не изменены. Карточки оформлены с помощью генерации изображений; мелкие детали изображения могут отличаться от исходного фото. Обозначения выходов на старом блоке сохранены по фото; суммарная мощность подписана по сайту.

Папку images ChatGPT из архива можно поместить рядом с исходной images в F:\РАБОТА\DGINNI.RU. Запись в папку F: в текущем сеансе не предоставлена.
