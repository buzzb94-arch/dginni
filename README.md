# Джинн — сайт приборов автоматизации (dginni.ru)

Одностраничный сайт: pH-метр, pH-контроллер и блоки управления микроклиматом «Джинн».

**Смотреть сайт:** https://buzzb94-arch.github.io/dginni/

## Состав

- `index.html` — весь сайт (HTML, CSS и JS в одном файле)
- `images/` — фото для сайта (оптимизированные копии)
- `docs/` — PDF-инструкции
- `ФОТО/`, `pH метр Джинн/`, `pH контроллер Джинн/`, `БУ универсальный/`, `БУ универсальный с высокой выходной мощностью/`, `ВОПРОСЫ/` — исходные фото и документы

## Где менять данные

В начале скрипта в `index.html`:

- `CONFIG` — телефон, почта, ссылки на мессенджеры и маркетплейсы, инструкции, реквизиты
- `IMAGES` — пути к фотографиям
- `PRODUCTS` — каталог: цены, характеристики, комплектация
- `VELARIS` — цвета и скорость живого фона
